# 1ClickDL — official downloads

Desktop video downloader for macOS and Windows.

Website: [1clickdl.com](https://1clickdl.com)

This repository contains distribution files and signed update feeds only. It does not contain the proprietary application source, user data or signing keys.

Initial system support: macOS 13 or later on Apple Silicon; Windows 10/11 x64 on Intel or AMD. The initial installers do not have an Apple Developer ID or Windows Authenticode publisher signature. Installation instructions are provided on the website. Update authenticity is checked separately using the public keys embedded in the application.

Third-party tools keep their own open-source licences. Their available notices and corresponding source materials are provided separately from the proprietary application licence.
